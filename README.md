Система обнаружения веб-атак

Автор: Ибрагимов Амир, 8 класс.
Суть проекта: Программа на Python для автоматического анализа логов веб-сервера. Она находит SQL-инъекции, XSS, Path Traversal и другие атаки, а затем формирует удобный отчет.

Зачем это нужно?
Крупные компании покупают дорогие системы защиты (SIEM), а у школ и малого бизнеса нет на это денег. Мой проект — бесплатная альтернатива. Он работает на любом ноутбуке, не требует мощных серверов и позволяет администратору вовремя заметить взлом.

Как это работает:
1. Читает файл `logs.txt`.
2. Ищет атаки по правилам из `signatures.json` (используя регулярные выражения).
3. Отправляет уведомления в Telegram (если есть критическая угроза).
4. Генерирует красивый дашборд с графиками (HTML + Chart.js).
